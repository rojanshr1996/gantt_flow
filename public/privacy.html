Privacy Policy

Gantt Flow Application

Last Updated: August 7, 2026

Gantt Flow ("we", "our", or "us") is committed to protecting user privacy and maintaining complete transparency regarding data access. This Privacy Policy explains how Gantt Flow accesses, processes, stores, and safeguards your information.

1. Information That Is Collected

Gantt Flow collects and processes only the minimum necessary information required for account sign-in and schedule management:

  • Basic Profile Information: User ID, Display Name, Email Address, and Profile Picture URL provided directly by Google Authentication during sign-in.
  • Calendar & Event Metadata: Calendar names, IDs, event titles, start/end dates and times, event descriptions, location, attendee email lists, and attachment references.
  • Google Drive File References: File IDs, file names, icon links, and web view URLs for Google Drive files you explicitly select to attach to calendar events.

2. Google APIs Used

Gantt Flow integrates with the following official Google APIs:

  • Google Sign-In & Firebase Auth: For secure user authentication.
  • Google Calendar API V3: Requested minimum scopes: https://www.googleapis.com/auth/calendar.events & https://www.googleapis.com/auth/calendar.readonly
  • Google Drive API V3 (Read-Only): Requested scope: https://www.googleapis.com/auth/drive.readonly

3. Why Google Calendar Access Is Needed

Access to Google Calendar APIs (https://www.googleapis.com/auth/calendar.events & https://www.googleapis.com/auth/calendar.readonly) is strictly required to:

  • Read your existing Google Calendars and events to build the horizontal timeline bars on the Gantt chart display.
  • Allow you to create new events, modify start/end timing or event details, and delete events directly within Gantt Flow, keeping your Google Calendar synchronized in real time.

4. Why Google Drive Access Is Needed

Access to the Google Drive API (https://www.googleapis.com/auth/drive.readonly) is strictly required to:

  • Display a list of your existing Google Drive files in a file selector picker when you choose to attach document or image reference links to specific calendar events.
  • Gantt Flow uses read-only access and cannot create, modify, or delete any files in your Google Drive.

5. Data Storage & Retention Policy

Is your personal calendar or file data stored on remote servers? No.

  • Gantt Flow operates entirely client-side. Your calendar events, Drive files, and profile data are processed locally on your device and are never sent to external servers or third-party databases.
  • OAuth authentication access tokens and user display settings are securely cached on your local device using encrypted native storage (SharedPreferences / Keychains).

6. Data Deletion Policy & User Rights

You retain full control over your data and access permissions:

  • Local Data Removal: Tapping "Sign Out" inside the Gantt Flow application immediately purges all cached authentication tokens and local user data from your device.
  • Revoking Access: You can permanently revoke Gantt Flow's access to your Google account at any time by visiting Google Account Permission Settings.
  • Account Deletion: Because Gantt Flow does not store your data on external databases, revoking permissions and signing out completes full data deletion.

7. Compliance with Google API Services User Data Policy

Gantt Flow's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
